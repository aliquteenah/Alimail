ALI MAIL — نسخة الهاتف

الملفات:
- index.html
- server.js
- package.json

التشغيل على أندرويد:
1) ثبّت تطبيقًا يدعم Node.js/Termux.
2) ضع مجلد ALI-MAIL داخل مساحة التطبيق.
3) افتح الطرفية داخل المجلد.
4) نفّذ:
   npm install
5) ثم:
   npm start
6) افتح في المتصفح:
   http://127.0.0.1:8080

ملاحظة: النظام يعتمد على خدمة 1secmail الخارجية، لذلك يجب أن يكون الإنترنت متاحًا.
